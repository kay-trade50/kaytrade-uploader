プライバシーポリシー

kaytrade-uploader は、運営者本人の YouTube チャンネルに対してのみ、YouTube Data API を通じて動画のアップロード、動画情報・公開設定の更新、再生リストへの追加、コメントの投稿を行います。

  • 取得した認証情報は運営者本人のパソコンの中にだけ保存し、第三者に提供・送信しません。
  • 運営者以外のユーザーのデータは収集・保存しません。
  • Google API から受け取った情報は、上記の目的以外には使いません。

Privacy Policy

kaytrade-uploader uses the YouTube Data API only on the owner's own YouTube channel, to upload videos, update video details and publishing settings, add videos to playlists and post comments. Credentials are stored only on the owner's computer and are never shared with or sent to third parties. No data about other users is collected or stored. Information received from Google APIs is used only for these purposes.
