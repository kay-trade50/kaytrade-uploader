プライバシーポリシー

card-shop-rpg は、運営者本人の YouTube チャンネルに対してのみ、YouTube Data API を通じてコメントの読み取り・返信・評価・非表示などの管理と、チャンネルメンバー一覧の読み取りを行います。

取得した認証情報とデータは運営者本人のパソコンの中にだけ保存し、第三者に提供・送信しません。

読み取ったコメントやメンバーの情報は、チャンネル運営(返信やメンバー優先の対応)のためだけに使い、販売や広告には使いません。

Google API から受け取った情報は、上記の目的以外には使いません。

Privacy Policy

card-shop-rpg uses the YouTube Data API only on the owner's own YouTube channel, to read, reply to, rate and moderate comments and to read the list of channel members. Credentials and data are stored only on the owner's computer and are never shared with or sent to third parties. Comment and member information is used only to run the channel (replying to viewers and prioritizing members) and is never sold or used for advertising. Information received from Google APIs is used only for these purposes.
